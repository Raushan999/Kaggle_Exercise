## Git commands used:-

* checking the person's detials for git profile

- git config --global user.name
- git config --global user.email
- git config --global user.name "Raushan999"

* Initialize and add the changes to target repository.

- git init
- git remote add origin https://github.com/Raushan999/Kaggle_Exercise.git
- git add .
- git commit -m "a beautiful commit message"
- git branch -M main
- git push -u origin main


* when working to your feature branch:- 
- git checkout -b "feature_branch"
- - stage the changes
- - Commit the message
- - push the changes to feature branch
- git push origin feature_branch
